M-score 评估与培训工具

用于非哺乳期乳腺炎 / 肉芽肿性乳腺炎的疾病严重程度评估、随访记录和评分培训。本工具为研究与教学用途，不替代临床判断。

工具简介 评分定义 在线评分 培训病例 引用与说明

一、工具简介

M-score 由病灶大小、红斑、瘘管/溃破、疼痛或压痛、生活质量影响等维度构成，用于描述患者当前疾病严重程度。M-active-score 进一步聚焦炎症活动性表现。

推荐使用场景：基线评估、治疗后随访、疗效观察、研究数据采集、评分者培训。
重要说明：请勿在本网页中输入任何可识别患者身份的信息。若上传或展示病例图片，请先完成去标识化处理。

二、M-score 条目定义

1. 病灶大小

测量乳房肿块的最大径线。查体时四指并拢轻柔触诊，先健侧后患侧，先正常区域后病灶区域。若存在多个肿块，需将肿块最大径线相加。

仅针对查体可触及病灶；不纳入单纯影像学病灶；正常腺体增生结节或纤维腺瘤不予计算。

分值定义
0 分无触诊肿块
1 分触诊肿块 ≤ 3 cm
2 分触诊肿块 > 3 cm

2. 红斑

视诊为主，结合当前症状。触诊病灶表面皮肤并与周围正常皮肤比较，确认有无充血发热。

血管充盈征：轻柔按压红斑中心区域，移开手指后按压处皮肤由白转红，提示活动性红斑。需与恢复期色素沉着鉴别。

分值定义
0 分无活动性红斑
2 分有活动性红斑

3. 瘘管 / 溃破

检查乳房有无皮肤破溃或窦道。视诊为主，并询问患者自上次评估后有无流脓及愈合情况。

若初诊无窦道，由穿刺引起的“窦道”不认为是窦道形成。

分值定义
0 分无瘘管 / 溃破
1 分近一周有破溃流脓，但查体未见
2 分查体见破溃流脓

4. 疼痛 / 压痛

采用视觉模拟评分 VAS。0 分为无痛，10 分为此前从未体验过的难以忍受的剧烈疼痛。

M-score-a 使用患者当前自觉疼痛；M-score-t 使用查体压痛。每次评估时建议提醒患者上次 VAS 评分，或以对侧乳房对称位置作为 0 分参照。

分值定义
0 分VAS 0–3
1 分VAS 4–6
2 分VAS 7–10

5. 生活质量影响

询问疾病对患者生活质量的影响，包括工作、日常活动、穿衣、睡眠、伤口处理和是否需要治疗介入等。

分值定义
0 分无影响
1 分轻度影响
2 分重度影响

三、计算规则

指标计算规则
M-score-a病灶大小 + 红斑 + 瘘管/溃破 + 疼痛（患者自评） + 生活质量影响
M-score-t病灶大小 + 红斑 + 瘘管/溃破 + 疼痛（压痛） + 生活质量影响
M-active-score红斑 + 瘘管/溃破 + 疼痛（压痛）
建议 ResolutionM-score-t ≤ 1；若无法准确评估压痛，可参考 M-score-a ≤ 1
建议 Inflammatory remissionM-active-score = 0

四、在线评分器

请选择各条目分值，系统将自动计算 M-score-a、M-score-t 和 M-active-score。

五、培训病例

阅读病例后，可先自行评分，再点击“查看标准答案”。图片位置可替换为已去标识化的临床照片或示意图。

Case 1

图片参考：请替换为去标识化图片

47岁女性，诉确诊非哺乳期乳腺炎半年，B超提示 4 × 4 cm 良性肿块，患者 1 周前接受病灶内注射。查体：触诊肿块大小 6 × 4 cm，血管充盈征阴性，可见病灶内注射针口结痂，近一周无破溃流脓，疼痛自评 3 分，压痛 4 分，日常工作生活中偶尔会刺痛，无需频繁处理伤口，生活质量影响轻度。

标准答案：

M-score-a = 病灶大小 2 分 + 红斑 0 分 + 瘘管/溃破 0 分 + 疼痛（患者自评）0 分 + 生活质量影响 1 分 = 3 分。

M-score-t = 病灶大小 2 分 + 红斑 0 分 + 瘘管/溃破 0 分 + 疼痛（压痛）1 分 + 生活质量影响 1 分 = 4 分。

解释：病灶内注射针口结痂，近一周无破溃流脓，说明愈合倾向，瘘管/溃破记为 0 分。1 周前接受病灶内注射，皮肤轻微瘀斑，未见活动性发炎，血管充盈征阴性，红斑记为 0 分。

Case 2

图片参考：请替换为去标识化图片

33岁女性，诉确诊非哺乳期乳腺炎 1 年，B超提示 2 × 3 cm 良性肿块，患者半年内未接受治疗。查体：触诊肿块大小 2 × 2 cm，血管充盈征阴性，皮肤外观与正常无异，疼痛自评 0 分，压痛 0 分，日常工作生活中无任何影响，生活质量影响无。

标准答案：

M-score-a = 病灶大小 1 分 + 红斑 0 分 + 瘘管/溃破 0 分 + 疼痛（患者自评）0 分 + 生活质量影响 0 分 = 1 分。

M-score-t = 病灶大小 1 分 + 红斑 0 分 + 瘘管/溃破 0 分 + 疼痛（压痛）0 分 + 生活质量影响 0 分 = 1 分。

解释：患者无活动性炎症表现，M-active-score = 0。根据建议定义，M-score-t ≤ 1，可认为达到 Resolution；M-active-score = 0，可认为达到 inflammatory remission。

Case 3

图片参考：请替换为去标识化图片

35岁女性，诉确诊非哺乳期乳腺炎 3 个月，B超提示 5 × 8 cm 良性肿块，患者已接受 2 周抗结核治疗，效果不佳。查体：触诊肿块大小 8 × 6 cm，血管充盈征阳性，皮肤肿块处破溃，疼痛自评 7 分，压痛 10 分，日常工作生活中经常需要处理伤口，严重时更换衣物困难，入睡困难，对疾病状态感到焦虑，生活质量影响重。

标准答案：

M-score-a = 病灶大小 2 分 + 红斑 2 分 + 瘘管/溃破 2 分 + 疼痛（患者自评）2 分 + 生活质量影响 2 分 = 10 分。

M-score-t = 病灶大小 2 分 + 红斑 2 分 + 瘘管/溃破 2 分 + 疼痛（压痛）2 分 + 生活质量影响 2 分 = 10 分。

解释：患者存在大病灶、活动性红斑、破溃流脓、重度疼痛及明显生活质量受损，提示疾病状态严重，需进一步评估并及时干预。
